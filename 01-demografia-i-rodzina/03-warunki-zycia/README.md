# Warunki życia rodzin

[← Demografia i rodzina](../README.md)

> Jakie bariery materialne i organizacyjne zgłaszają rodziny?

## Zakres badań

- Dostępność i metraż mieszkań
- najem
- usamodzielnianie
- praca i dochody
- jedna pensja a budżet rodziny
- koszty dzieci
- opieka domowa i instytucjonalna
- transport
- pomoc rodzinom dzieci z niepełnosprawnościami

## Status

Plan badań. Dane, cytaty i wnioski wymagają zebrania i weryfikacji.
